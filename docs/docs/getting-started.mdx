---
title: "Get started"
description: "Connect a provider, choose a model, and create an image."
---

First [build and run Illustrate](/docs/build-from-source). You also need an
account and credentials for a supported provider. Provider billing is separate
from the app; a consumer chat subscription may not include API access.

<Steps>
  <Step title="Choose a project">Use the default project or create one for the work you want to keep together.</Step>
  <Step title="Link a provider">Open **Providers**, choose your provider, and enter the requested credentials. The form links to its setup page. Credentials are stored in Apple Keychain.</Step>
  <Step title="Create an image">Open image generation, choose a model, enter a prompt, and review its settings and estimated cost. Submit only when you are ready to incur provider charges.</Step>
  <Step title="Review the result">Follow progress in the generation queue. Open completed results to inspect, save, or share them. A queued request is not a completed generation.</Step>
</Steps>

If a request fails, check the selected model, API permissions, and balance
in the provider's console. Providers can retire models or restrict them by
account or region. Before resubmitting an uncertain paid request, check
whether the provider already accepted it.
