---
title: "Illustrate"
description: "Create images and videos in a native Apple app using your own AI provider accounts."
---

Illustrate is a SwiftUI app for iPhone, iPad, and Mac. It sends generation
requests directly to the AI providers you connect. You do not need to deploy
a server or create an Illustrate account.

Use it for single image and video requests, chat threads, bulk sessions,
storyboards, Flow Canvas, agent workflows, and product photoshoots. Projects
keep each job's provider connections and saved work together.

<Warning>
  Your providers bill usage separately. Review generation settings and the
  provider's current pricing before submitting work. In-app estimates can
  differ from the final charge.
</Warning>
